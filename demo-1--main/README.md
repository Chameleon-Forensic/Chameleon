# remote-forensic-imager

Uzaktan (SSH) disk imajı alan, write-blocker + SHA-256 doğrulama +
chain-of-custody loglama içeren adli bilişim aracı. Kapsam ve kurallar
için `docs/PROJE_TALIMATI.md`'ye bakın.

## Kurulum

```bash
pip install -r requirements.txt
```

## Çalıştırma

```bash
cd local_collector
python main.py
```
